# Waves Animation

A simple and smooth waves animation built using only HTML and CSS.

![Waves animation screenshot](./Screenshot%202024-08-13%20092315.png)

## Demo

Open index.html in your browser to see the animation locally.

## Features

- Pure HTML and CSS (no JavaScript required)
- Lightweight and responsive
- Easy to customize colors, speed and size

## Files

- `index.html` — the demo markup
- `style.css` — the animation styles
- `Screenshot 2024-08-13 092315.png` — project screenshot

## How to use

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Waves-Animation.git
   ```

2. Open `index.html` in your browser (double-click or drag into the browser window).

3. To customize the animation look and behavior, edit `style.css`.

## Customization tips

- Change the gradient and background colors in `style.css` to match your site.
- Adjust animation duration to speed up or slow down the waves.
- Modify the wave heights and positions to create different effects.
